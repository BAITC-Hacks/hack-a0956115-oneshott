# Тексеру есебі

Тексерілген орта: Linux, Python 3.12, Node.js 24; Chromium 153 және Playwright. Қосымшаның өзі тек Python стандартты кітапханасын талап етеді. Node.js пен Playwright тек әзірлеушілік QA үшін қолданылды.

## Автоматты тексерулер

| Тексеру | Нәтиже | Қамтылғаны |
|---|---|---|
| Python unittest | **14 / 14 өтті** | бизнес логикасы және шынайы HTTP API |
| JavaScript синтаксисі | **Өтті** | `node --check static/app.js` |
| Python компиляциясы | **Өтті** | `server.py`, `domain.py` |
| Frontend render smoke | **Өтті** | 10 бет күйі, 3+ сұрақ, 10 өңделетін өріс, сүзгі, XSS escape, серверлік рейтинг |
| Chromium E2E | **Өтті** | енгізу → сұрақтар → рейтинг → жариялау → ұсыныс → қолмен шешім → кезең → +30 ұпай |
| Браузер JavaScript қателері | **0** | толық E2E кезінде |
| Тар экран | **Өтті** | 390×844 өлшемінде каталог бетінде сыртқы көлденең жылжу жоқ |

### Python тестілерінің мазмұны

1. Өңдеу рейтингті қайта есептейді; каталог сұрыпталады; ескі revision қабылданбайды; база қайта инициализацияланғанда дерек сақталады.
2. Тұтас сценарийде екі команда таңдалады; ұпай тек растаудан кейін; қайталанған растау 409.
3. Қауіпті `javascript:` URL, қысқа AI кірісі, бөгде Origin және база файлына статикалық жол қабылданбайды.
4. Төмен рейтинг барлық командаға көрінеді; бір команда бір міндетке жеті ұсыныс жібере алады.
5. Жариялау үшін барлық толтырылған өріс расталады; расталмаған жоба сақтала алады.
6. Кезең түсініктемемен қайтарылады, қайта жіберіледі және кейін расталады; қабылдамау қолмен орындалады.
7. Студент бизнес шешімін орындай алмайды; таңдалмаған/бөгде команда кезең жібере алмайды.
8. Жарияланбаған жоба студентке көрінбейді және ұсыныс қабылдамайды.
9. AI кемінде үш сұрақ береді; белгісіз фактілер бос; жауаптар дәл көшіріледі.
10. Жарамсыз JSON, ойдан қосылған дерек және provider timeout қауіпсіз fallback береді.
11. Карточка мен растау тізімінің форматы тексеріледі.
12. Расталмаған мән ұпай қоспайды; жеті салмақтың қосындысы 100.
13. 39/40, 69/70, 89/90 деңгей шекаралары; сансыз табыс критерийі ұпай алмайды.
14. Бастапқы жиынтықтың әр түрі кемінде бес; бастапқы ұпайлар 100, 90, 75, 45, 20.

### Браузерде орындалған сценарий

1. Каталогта 5 карточка; «Жоба» сүзгісінде 1 карточка.
2. Әлсіз демо сипаттама енгізілді; кемінде 3 сұрақ алынды.
3. Демо жауаптардан өңделетін карточка құрылды; бастапқы растаусыз ұпай 0.
4. Деректер расталды: 20. Контекст пен қажеттілік қосылды: 40. Барлық мәлімет расталды: 100.
5. Деректер өрісі босатылды: растауы алынды және ұпай 80. Қайта толтырылып расталды: 100.
6. Карточка жарияланды.
7. Студент рөлімен идея, жоспар, мерзім және сілтемесі бар ұсыныс жіберілді.
8. Бизнес оны қолмен таңдады.
9. Студент прототип кезеңін дәлел сілтемесімен жіберді.
10. Бизнес нәтижені растады. Команда бетінде 30 ұпай көрсетілді.
11. Бет жаңартылғаннан кейін каталогта 6 міндет сақталды.
12. 390×844 өлшеміне ауыстырылып, бет енінен шығу тексерілді.

Скриншоттар: `docs/screenshots/01-catalog.png`, `02-rating-editor.png`, `03-confirmed-result.png`, `04-team-points.png`, `05-mobile.png`.

Алғашқы Chromium жүктеу тәсілі орындалмады. Балама Chromium пакетімен шынайы браузерлік тест аяқталды. Бірінші өтуде мобильді каталогтың көлденең жылжуы анықталып, түзетілгеннен кейін тест сәтті қайталанды.

## Қайта орындау

```bash
python3 -m unittest discover -s tests -v
node --check static/app.js
```

Render smoke үшін алдымен қосымшаны іске қосыңыз:

```bash
node tests/render_smoke.cjs http://127.0.0.1:8000
```

Шынайы браузерлік E2E үшін бөлек әзірлеу ортасында:

```bash
npm install --no-save playwright
npx playwright install chromium
node tests/browser_e2e.cjs
```

E2E жеке уақытша база мен автоматты бос порт қолданады. `SANA_PYTHON` Python командасын, `SANA_CHROMIUM_PATH` дайын браузер жолын, `SANA_SCREENSHOTS` скриншот бумасын ауыстырады. Node 18+ қажет; тест жасаған кезде 24 қолданылды.

## Тексеру шекарасы

Windows-тағы `start.bat` файлы осы Linux ортасында орындалған жоқ; стандартты `py`/`python` командаларына арналған. Safari және Firefox бөлек тексерілмеді. Жүктеме, өндірістік аутентификация және нақты сыртқы AI API тесті бұл MVP көлеміне кірмейді. API рөл тексерістері демо рөлге сүйенеді және production қауіпсіздігі ретінде ұсынылмайды.
