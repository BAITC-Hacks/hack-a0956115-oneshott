# AI Sana Challenge Hub

MVP для практического хакатона: бизнес описывает задачу, дополняет её с помощью уточняющих вопросов, подтверждает карточку и публикует её. Студенческие команды просматривают общий каталог и отправляют предложения. Бизнес вручную принимает или отклоняет отклики.

## Запуск

Нужен Python 3.9 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

На Windows активируйте окружение командой `.venv\\Scripts\\activate`.

## Что есть в MVP

- Создание и редактирование бизнес-задачи.
- Локальная демонстрационная AI-функция: анализ пропусков и генерация минимум трёх уточняющих вопросов. Код показывает промпт, входной и ожидаемый выходной формат, проверку формата и резервные вопросы.
- Рейтинг готовности 0–100 только за заполненные и подтверждённые поля.
- Общий каталог опубликованных задач с сортировкой и фильтрами по теме и уровню готовности.
- Пять демонстрационных профилей команд и предложения.
- Предложение команды с идеей, планом, сроком и ссылкой на прототип; ручной выбор или отклонение бизнесом.
- Начисление одного балла команде за каждый подтверждённый бизнесом этап.

Внешний AI API, регистрация, база данных и производственная инфраструктура не требуются. Задачи и отклики хранятся в сессии приложения и сбрасываются при её завершении. Все данные в демо синтетические.

## Формула готовности

| Критерий | Баллы |
|---|---:|
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 |
| **Итого** | **100** |

В составных критериях баллы делятся поровну между полями: контекст и потребность дают по 10 баллов; контакт и формат взаимодействия — по 5. Баллы начисляются только когда поле заполнено и подтверждено. Рейтинг пересчитывается после сохранения карточки.

- 0–39 — черновик, виден в каталоге с пометкой, что его стоит уточнить.
- 40–69 — рабочая задача, команды могут откликаться.
- 70–89 — готовая задача, получает более высокую позицию.
- 90–100 — приоритетная задача.

Низкий рейтинг не скрывает задачу и не запрещает отклики. AI не добавляет сведения в карточку и не назначает команды.

## Ручной сценарий демонстрации

1. Откройте «Рабочее место бизнеса» и создайте короткий черновик, например: «Хотим улучшить продажи с помощью AI».
2. Покажите вопросы о пользователях, доступных данных, ожидаемом результате и критериях успеха.
3. Дополните карточку, отметьте подтверждение сведений и сохраните её. Покажите рост рейтинга и расшифровку.
4. Опубликуйте задачу и откройте «Каталог для команд».
5. Отправьте предложение от одной из команд.
6. В «Откликах бизнеса» вручную выберите или отклоните предложение.
7. Для выбранной команды подтвердите выполненный этап и покажите начисленный балл.
